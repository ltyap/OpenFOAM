# README #

This is an adaptation of the exisitng OpenFOAM utility `postChannelFlow` for annular channel flow for OpenFOAM v9, which allows one to average the solution of an annular channel flow simulation over the azimuthal- and streamwise directions. The original utility can be found [here](https://github.com/timofeymukha/postChannelFlow)
To run the utility just write postAnnularFlow in the command-line.
The utility expectes a file called postAnnularDict in the constant directory.
A sample dictionary can be found in the repository.
